# 阶段三前半段：本地检索器优化报告

## 实验设置

- 数据：ChartQA medium，386 张页面、800 条问答。
- 划分：600 train / 100 dev / 100 test，按页面和文档隔离。
- 基础模型：`google/siglip-base-patch16-224`。
- 训练方式：冻结 SigLIP，训练共享 rank-8 残差适配层，InfoNCE 损失。
- 模型选择：仅根据 dev MRR@10 早停，test 只用于最终报告。

## 结果

| 方法 | 最佳 epoch | Test Recall@1 | Test Recall@3 | Test Recall@10 | Test MRR@10 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 零样本 SigLIP | 0 | 0.23 | 0.28 | 0.37 | 0.2661 |
| 共享适配层，lr=1e-4 | 130 | **0.27** | **0.32** | 0.41 | **0.3060** |
| 共享适配层，15 个 hard negatives | 54 | 0.25 | 0.29 | **0.44** | 0.2937 |

普通负样本方案将 Test MRR@10 从 0.2661 提升到 0.3060，相对提升约 15.0%；Recall@1 从 0.23 提升到 0.27。hard negative 方案获得最高 Recall@10，但前排排序质量低于普通负样本方案，因此不作为当前主检查点。

学习率 `1e-3` 的消融实验出现明显过拟合：训练指标持续提高，而 dev MRR 快速下降。正式配置采用 `1e-4`，rank 为 8，早停耐心值为 150。
